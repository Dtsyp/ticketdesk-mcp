# Ревью: MCP-сервер TicketDesk

## Контекст

Перед тобой код MCP-сервера, который мы выкатили в прод на прошлой неделе.
Как он работает: агенты (Claude Desktop через stdio, наш orchestrator через
streamable HTTP) ходят в него и получают тикеты и вложения.

Мы хотим услышать твоё код-ревью.

## Что делать

1. Прочитай `README.md`, `server.py`, `auth.py`, `storage.py`, а также
   обвязку (`Dockerfile`, `docker-compose.yml`, `.gitlab-ci.yml`, `.env`,
   `tests/`), а также тестовые данные в `data/`, `keycloak/`.
2. Проведи код-ревью. Для каждого выявленного места для улушения опиши: что можно улучшить, как отсутствие улушений влияет на проект,
   расставь приоритеты для выкатки улучшений.
3. Для находок из пункта 2 напиши код для улучшений/фиксов ввиде патчей/диффов.


## Уточнения

- Не обязательно переписывать проект целиком, нас больше интересует разбор узких мест и ход мыслей, а не рефакторинг.
